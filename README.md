# Nicola Iantomasi

Formatore e consulente di **Intelligenza Artificiale e Data Analysis**, fondatore di
[Yimp](https://www.yimp.it/) (Genova, dal 2019) e della
[Scuola dei Dati](https://www.yimp.it/la-scuola-dei-dati-patreon/).

Insegno AI generativa, LLM, RAG, agenti AI, Machine Learning e analisi dei dati
con Python, SQL, Excel e Power BI. Oltre 3.000 ore di docenza e 3.000 studenti
formati, laurea magistrale in Matematica all'Università di Pisa. Lavoro con i dati
dal 2014, a partire dai Data Warehouse di una banca online.
